## Features

- User Authentication (Email/Password & Google Sign-In)
- Transaction Management (Add, Edit, Delete)
- Budget Tracking with AI Insights
- Data Visualization (Category Charts)
- Dark/Light Theme
- Responsive Design

## Tech Stack

- **Frontend:** React 19, React Router, Firebase Auth, Recharts
- **Backend:** Next.js 16, Node.js, MongoDB, Firebase Admin SDK
- **Deployment:** Vercel, MongoDB Atlas, Firebase
